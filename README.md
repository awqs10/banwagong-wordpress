### 第二步：登录 KiwiVM 控制面板

进入用户中心 → My Services → 找到购买的 VPS → 点击 Open KiwiVM。

KiwiVM 是搬瓦工自研的管理面板。在这里可以：查看 IP 地址和 SSH 端口、安装操作系统、重启/关机、迁移机房、查看流量使用情况。

建议新手选 **Ubuntu 22.04** 或 **Debian 12**，稳定且资料多。

### 第三步：用 SSH 工具连接服务器

连接 VPS 需要：**IP 地址 + SSH 端口 + root 密码**。

注意：搬瓦工默认 SSH 端口**不是 22**，在 KiwiVM 的 Main Controls 页面可以查到实际端口号。

- Windows 用户推荐 **Xshell**（免费家庭版）或 **PuTTY**
- Mac/Linux 用户直接用终端，命令格式：`ssh root@你的IP -p 端口号`

连接成功后，你就进入了服务器的命令行界面，接下来可以开始部署建站环境。

### 第四步：安装建站环境（推荐宝塔面板）

命令行对新手不友好。最省心的方案是安装**宝塔面板**——有图形界面，建站、管理数据库、配置 SSL 都能点点鼠标搞定。

在服务器命令行中运行以下命令（Ubuntu/Debian 系统）：

bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec


安装完成后，面板会显示登录地址和默认账号密码。打开浏览器访问面板地址，登录即可。

如果你更倾向于纯命令行方案，也可以选择 **LNMP 一键包**（Linux + Nginx + MySQL + PHP），小内存 VPS 尤其推荐 Nginx，资源占用比 Apache 低很多。

### 第五步：添加网站和域名解析

1. 在宝塔面板点击「网站」→「添加站点」，填入你的域名
2. 去域名注册商后台，将域名 A 记录解析到搬瓦工 VPS 的 IP 地址
3. 解析生效通常需要几分钟到几小时，可以用 ping 命令验证

域名可以在 Namecheap、Dynadot 等平台购买，很多后缀现在都很便宜。

### 第六步：安装 WordPress

WordPress 安装最简单的方式是通过宝塔面板的「一键部署」功能，在软件商店里找到 WordPress 直接安装，全程图形化操作，不需要敲命令。

手动安装的话：把 WordPress 压缩包解压上传到网站根目录（宝塔默认在 `/www/wwwroot/你的域名/`），然后在浏览器访问域名，跟着安装向导填写数据库信息即可。

安装完成后，建议立即：配置 SSL 证书（宝塔面板一键申请 Let's Encrypt 免费证书）、安装缓存插件（如 WP Super Cache）、设置固定链接格式。
